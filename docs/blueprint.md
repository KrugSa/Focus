# **App Name**: Veloce Dashboard

## Core Features:

- Global Command Bar: A keyboard-first search and task command tool powered by AI to allow users to orchestrate tasks across all projects using simple text input.
- Universal Task Rapid-Entry: Ultra-minimal dialog optimized for high-speed ticket capture, supporting direct PR/Ticket ID linking and priority setting.
- Intelligent Schedule Balancer: A tool that analyzes daily capacity to automatically suggest the best focus windows and shift low-priority blocks based on historical estimation drift.
- Hybrid Kanban Workspace: A sophisticated developer-centric view that combines Jira-style boards with a compact list view for managing high ticket volumes across multiple projects.
- Live Pulse Timer: A persistent floating active ticket widget for one-click status updates, automated tracking, and rapid task switching.
- Productivity Scorecard: Dynamic analytics dashboard visualizing estimation accuracy, focus streaks, and AI-detected interruption patterns.
- Visual Daily Canvas: Interactive hourly timeline for drag-and-drop task allocation and urgent bug insertion with a 'Focus Session' lock-down mode.

## Style Guidelines:

- Dark mode by default, featuring a 'Deep Space' theme. Primary color: Electric Indigo (#7C71FF) symbolizing velocity. Background: Midnight Grey (#0D0D11), slightly desaturated for high contrast without glare. Accent: Azure Burst (#00D1FF) for critical notifications and timers.
- Font pairing: 'Space Grotesk' for headlines and ticket numbers to evoke a techy, precision-engineered feel; 'Inter' for body text and long-form task descriptions for maximum readability.
- Geometric, thin-stroke monoline icons following the Lucide style, using uniform 2px borders for a clean and technical dashboard appearance.
- A 'Hyper-Lean' layout inspired by Linear, featuring a thin collapsible sidebar, glassmorphic floating overlays, and dense data views to minimize vertical scrolling.
- Micro-interactions using spring physics for a tactile feel. Task transitions should use rapid 'fade-and-slide' effects to mimic the speed of high-performance tools like Raycast.
